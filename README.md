## 📖 Sobre o Projeto

O **SuS_ChatBot** nasce da necessidade de centralizar o atendimento e a gestão das informações. Diferente de sistemas convencionais onde o bot é o único foco, o "coração" deste projeto é o seu **Painel de Controle (Dashboard)**. É através do painel que todo o fluxo conversacional e os dados recolhidos pelo chatbot serão administrados, analisados e armazenados diretamente no Banco de Dados.

### ✨ Principais Recursos Planejados

- 📊 **Painel Administrativo (Recurso Principal):** Interface web para monitorizar métricas, gerir os dados e aceder ao histórico de interações.
- 🗄️ **Integração com Banco de Dados:** Armazenamento centralizado, seguro e estruturado de todas as informações geradas.
- 🤖 **Chatbot Interativo:** Interface conversacional dinâmica para o utilizador final interagir com o sistema.
- ⚙️ **Gestão de Fluxos:** Capacidade de adaptar e monitorizar o comportamento do bot diretamente através do painel.

## 🧠 Pensamentos, Ideias e Códigos

Como este é um projeto em construção, este espaço é dedicado à organização do raciocínio e estruturação dos próximos passos lógicos:

### 🏗️ Arquitetura Inicial (Rascunho)
* **Frontend (Painel):** Necessário escolher um framework reativo (ex: *React* ou *Vue.js*) para criar um dashboard analítico rápido.
* **Backend (API):** Servidor responsável por ser a ponte entre o Painel, o Chatbot e o Banco de Dados. (A avaliar: *Node.js* ou *Python*).
* **Banco de Dados:** Precisa suportar alta leitura/escrita devido aos logs do chat. (*PostgreSQL* para estruturação clássica ou *MongoDB* para flexibilidade).
